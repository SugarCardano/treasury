# Security

This repository contains public verification material for the SUGR Community Treasury.

## Never Share

Never disclose or commit:

- seed or recovery phrases
- private keys or signing keys
- wallet backup files
- wallet spending passwords
- hardware-wallet secrets
- API credentials
- browser-wallet databases
- internal signing configuration

The SUGR Community Revival Team will never need a community member's seed phrase or private key to verify a treasury transaction or legacy claim.
